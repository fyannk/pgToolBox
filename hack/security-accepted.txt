# Accepted findings, one per line:
#
#   scanner  id  package-or-path  reason (how it was shown)
#
# The third field is the package for dependency scanners (grype, osv-scanner,
# govulncheck) and the file path for code scanners (CodeQL, gosec), so a line
# covers only the one place that was reviewed; `*` matches any package or path
# and needs a reason that holds for every one of them.
#
# A finding is accepted only when it is shown to be unreachable (not compiled
# into what ships, or the vulnerable function is never called) or not a
# vulnerability where it stands (the flagged value is not secret, or an external
# format mandates the construct and nothing else can read it), and the reason
# says how that was shown (SECURITY.md, "How scan findings are triaged").
# "No fix available" is never a reason. Accepted findings stay on the Security
# page, marked as accepted, and are dismissed in code scanning with the same
# reason.
