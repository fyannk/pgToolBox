# pgToolBox console — the SPA and its design system

The console UI. It **renders Go view models** and derives
nothing: every health state, roll-up, threshold and verdict comes from the API.
A missing derivation is added to the Go API, never computed here.

## Layout

```
ui/
  tokens/                design tokens (tokens.css, source of truth for every UI; tokens.ts generated;
                         contrast.test.mjs = WCAG AA of every pair, both themes)
  src/ds/styles.css      Tailwind 4 mapped onto the tokens; default palette/scale switched off
  src/ds/patterns/       StatusChip, Provenance, VerdictBanner, DataTable, Drawer, ConfirmDialog,
                         OperationTracker, States, BlindSpots, LiveBanner, Tabs, CommandPalette,
                         LogViewer, TopologyView, MetricChart, MetricTile, DiffViewer, AccessRequestCard
                         (+ stories, tests)
  src/screens/           ClusterList, Overview, Instances, Events, Diagnostics (+ triage) and the
                         cluster sections (replication, backups, storage, objects, history, metrics,
                         operations, logs, admin)
  src/routes/            TanStack Router file routes → src/routeTree.gen.ts (generated)
  src/api/fetcher.ts     the one HTTP function (RFC 9457 problems, 401 reauth, 403 role)
  src/api/live.ts        SSE invalidations + polling backstop (2 s → 5 s → 10 s while down)
  src/api/operations.ts  operation trackers (sessionStorage + server lookup)
  src/api/generated/     orval client + MSW handlers (generated, never edited)
  messages/{en,fr}.json  Paraglide catalogues
  mocks/                 MSW scenarios, the Go goldens as fixtures
  e2e/                   Playwright + axe + screenshot baselines
```

## Contract with the Go side

- **OpenAPI.** `orval.config.ts` reads `../internal/console/api/openapi.yaml`, generated by
  the Huma package that owns the routes (`make openapi`). `pnpm generate:check`
  regenerates the client and fails CI on drift.
- **Fixtures.** `mocks/fixtures/json/` are byte copies of `internal/console/api/testdata/fixtures/`
  (with its `manifest.json`); `scripts/sync-fixtures.mjs --check` fails when they drift, and
  `scenarios.gen.ts` makes tsc check every body against the OpenAPI type of its operation and
  status. `mocks/fixtures/index.ts` gives them readable names.
- **Stream.** `GET /api/v1/stream`: `hello` (the polling backstop's min/max, used as given),
  `invalidate {topic: clusters | cluster, namespace, name}`, `resync`, `reauth {expiresAt,
  refreshable}` (refreshable: the session is re-read, which renews it; otherwise a banner
  offers sign-in before it ends).
- **Errors.** Huma's RFC 9457 `ErrorModel`; the request id from `X-Request-Id`; 401 → sign in
  at `/auth/login?rd=<path>`; 403's `detail` names the role to ask for; 503 ("could not be
  asked") is retryable.
- **Operations.** `GET .../operations` (offers with allowed / requires / blockers /
  confirmation / observable, the promote roster), `POST` → 202 `OperationAccepted` (409 a
  precondition, 422 the confirmation), `GET /api/v1/operations/{id}` (phase ladder with the
  field each step was read from, deadline). `ConfirmDialog` (typed name; promote: the chosen
  instance) → `OperationTracker` (SSE + polling backstop, honest timeout, "not observable").
- **Logs.** `GET .../instances/{pod}/logs` (tail: checks access, lists containers, previous
  container) then `.../logs/stream` (SSE `line` / `gap` / `end`; a gap or a reconnection is a
  marker lines are never joined across).
- **Vocabulary and features.** `GET /api/v1/vocabulary` (health sort order, source-state
  health, link sections) is pinned by `src/app/vocabulary.test.ts`; `session.features` hides
  the sections a console does not serve.
- **Absent means not reported.** An omitted field is rendered "not reported", never 0/false.
- **Links.** `Contributor.link`, `Finding.link` and the drawing's box links resolve only onto
  this build's routes (`src/app/clusterLink.ts`): `""`, `instances`, `instances/<pod>`,
  `logs/<pod>`, `events`, `diagnostics`, `triage`, `replication`, `backups`, `storage`,
  `objects`, `history`, `history/<seq>`, `metrics`, `operations`, `insight`,
  `insight/<vacuum|blocking|statements|indexes|connections>`. Anything else is shown as
  text, never as a dead or guessed link; mapping a catalogue path is Go's job
  (`internal/console/status` `link()`).
- **Insight pack.** `GET …/clusters/{name}/insight` (one view model for the six insight screens:
  pack state, wraparound, statements, indexes, connections, lock graph), `GET …/insight/blocking?refresh=true`
  (polled every max(2 s, `minRefreshSeconds`) while the tab is visible), `GET /api/v1/insight/statements`
  (the team-wide page `/insight`). The console runs no SQL and ends no backend: statement text and
  `pg_terminate_backend` are pgAdmin's, linked from `pgAdmins`; Go's `textQuery` is shown with the
  row's queryid. A panel with `available: false` shows Go's `text`, never an empty table.
- **Access requests.** `GET /api/v1/access-requests` (per namespace: canRequest, canReview,
  seesAll; `writable` false when the console does not write), `POST …/namespaces/{ns}/access-requests`
  (201), `POST …/{name}/{approve|deny|revoke}` with `{note}` (required to deny). Each row carries
  Go's `actions` (four-eyes: never approve a request naming you; withdrawing your own is a deny),
  `scope` (shown verbatim: a named Cluster still binds the namespace) and the operator's
  `condition` (RoleBindingMissing is reported, never repaired). No SSE topic of their own: they
  refetch on `clusters` (`src/api/live.ts`).
- **Console extras.** `Operation.health` draws the tracker (overdue on the tracker's own clock
  is drawn unknown, like the server's timedOut); `OperatorWaiting.reasons[]` (`heuristic` labelled,
  `evidence[]` listed); `Metrics.chartSource` / `prometheus` / `rangeSeconds` / `stepSeconds` say
  where the charts come from and, when Prometheus is down, Go's reason for the fallback.
- **Personal pgAdmin server.** `POST …/clusters/{name}/database-roles` `{role, pgAdminUser?, inRoles?}`
  → 201 `PersonalDatabaseRole` (names only, never a password): the Overview's pgAdmin panel shows
  the role as declared, with Go's note, and says it is visible under "PgToolBox (personal)" only
  after the registration has run; 403/409/422/501/503 stay in the dialog in Go's words.
- **States without a golden.** `mocks/fixtures/extra.ts` builds the states no Go golden covers from the goldens.
- **Evidence refusals.** An `unavailable` or `stale` cross-check with a `reason` shows the reason
  verbatim as its headline ("not verifiable: audience mismatch (…)", "not verifiable: status not
  written by the operator (…)").
- **CSRF.** Every unsafe request carries `X-PgToolBox-Request: 1` (`src/api/fetcher.ts`,
  `internal/console/auth.RequestHeader`); the browser adds Origin / Sec-Fetch-Site.

## Embedding (`internal/console/uiassets`, served by `cmd/console`)

`make ui-build` writes `ui/dist/`: `index.html`, `assets/*` (content-hashed),
and `.br`/`.gz` siblings for text assets ≥ 1 KiB. `go:embed` cannot reach
outside its package, so `internal/console/uiassets` embeds a copy:
1. the console image's `ui` stage builds `ui/dist` and the Go stage copies it
   into `internal/console/uiassets/dist/` before `go build`; only a committed
   `.gitkeep` lives there, so `go build`/`go test` work without Node
   (`//go:embed all:dist`) and such a binary answers "SPA not embedded" (503);
2. `/assets/*`: `Cache-Control: public, max-age=31536000, immutable`, serve the
   `.br`/`.gz` sibling by `Accept-Encoding`; `index.html`: `no-store`; any other
   non-`/api`, non-probe path falls back to `index.html` (client routing);
   `/api/*` and probes never fall back;
3. CSP on `index.html` (no inline script or style exists in the build):
   `default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self';
   img-src 'self' data:; font-src 'self'; base-uri 'none'; form-action 'self';
   frame-ancestors 'none'` (`scripts/csp.ts` is the copy the harness runs under;
   keep them identical). `font-src 'self'` admits the self-hosted IBM Plex
   faces of `src/ds/fonts/` (SIL OFL 1.1, licence files beside them).
   The production build contains no MSW, no service worker and no faker.

## Rules this tree enforces

- Styling: semantic utilities on tokens only (`scripts/check-semantic.mjs`: no raw
  colour, no `style` prop, no `<style>`, no `dangerouslySetInnerHTML`). Base UI runs
  under `CSPProvider disableStyleElements`.
- Health is never colour alone: glyph + word + hue, `data-stale` modifier.
- Pessimistic actions: `ConfirmDialog` (typed name) → 202 → `OperationTracker`
  (SSE + polling backstop, honest timeout). Undo exists only as an audited inverse
  operation; the console never acts on its own.
- Keyboard: skip link, roving tabindex (Tabs), `aria-sort`, focus return from the drawer.
- Budgets (`.size-limit.json`): initial JS ≤ 180 KB gz, route chunk ≤ 60 KB gz, CSS ≤ 35 KB gz.

## Screens

Routes are under `/c/<namespace>/<cluster>` unless they start with `/`.

| Route                                    | What it shows                                                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `/`                                      | the Clusters the reader may get, across the team namespaces the console serves                               |
| `/c/<ns>/<cluster>` overview             | roll-up verdict with contributors, conditions, primary election, instance cards, capabilities                |
| `instances`, `instances/<pod>`           | the pod is the drawer's address; an unknown pod is the API's 404 in words                                    |
| `logs/<pod>` (container on the page)     | LogViewer; offered only with the logs capability                                                             |
| `metrics`                                | "now" tiles and the console's short ring, or history from the configured Prometheus with each chart's query  |
| `backups`                                | method, Backup objects, schedules (cron as CNPG reads it), recovery window, repository evidence cross-check  |
| `objects`                                | declarative objects with their PostgreSQL error, managed roles, tablespaces, poolers (desired vs ready pods) |
| `history`, `history/<seq>`               | DiffViewer: Go's structural diff with field managers, line view of the definitions                           |
| `diagnostics`                            | findings → incidents → playbooks as tabs                                                                     |
| `operations`                             | ConfirmDialog (typed name) → 202 → OperationTracker over SSE with polling backstop and an honest timeout     |
| `replication`, `storage`                 | the wiring drawing (TopologyView), walsenders/receivers/slots; PVCs and usage when reported                  |
| `/admin`                                 | PgAdmin/EvidenceAgent objects and console health                                                             |
| `/access`                                | the UI over `PgAccessRequest`: request form, my requests (phase, decided-by), review queue, withdraw, revoke |
| overview: pgAdmin → "my personal server" | a DatabaseRole of the reader's own registered in pgAdmin; shown when the console serves it                   |
| server-rendered `/auth/*`                | sign-in, denied and error pages, which stay JS-free; everything else requires JavaScript                     |
| Headlamp plugin (`headlamp/`)            | "Open in the console" + the phase the operator reports on the Cluster page; `make headlamp-check`            |
